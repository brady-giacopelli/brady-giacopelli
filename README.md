## Contribution snake

The snake is generated by the pinned [Platane/snk](https://github.com/Platane/snk) solver, so it follows the real profile-wide contribution calendar and searches for contribution cells by color while eating them. The `brady-seed` workflow adds dated commits only in this repository:

- The first applied run gives every date a baseline where needed and boosts the 84 BRADY pixels to a dynamic target of at least 100 contributions, or 25 above the current non-synthetic peak.
- Weekly rollover runs only backfill newly entered dates to one contribution. Existing pixel commits retain their authored dates and naturally shift left as GitHub's one-year window advances.
- Private and employer-repository commits are not changed. They remain part of the profile calendar when the GraphQL token can read them.

For the full profile-wide calendar, add a repository secret named `PROFILE_GITHUB_TOKEN` with permission to read user contributions (`read:user` for a classic token, or the equivalent read-only profile permission). Both workflows require this secret so private and internal contributions cannot be silently omitted from the target calculation.

Run `Seed BRADY contribution history` manually with `apply` unchecked first to inspect the plan. Then run it with `apply` checked once, wait for GitHub to recalculate the contribution calendar, and run `Generate Snake` manually. The weekly seed schedule and daily renderer schedule handle subsequent rollovers.
